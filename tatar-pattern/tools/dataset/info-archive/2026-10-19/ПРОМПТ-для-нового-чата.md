## Что где лежит

- Контактные листы: `Датасет/Прокси/<локация>/sheets/sheet_NN.jpg`, список — `sheets/index.txt`
- Прокси кадров: `Датасет/Прокси/<локация>/DSCxxxx.jpg`
- Главный файл: `Датасет/Разметка/<локация>/annotations.csv`
  (уже содержит размеченные пачки; их поля НЕ перезаписывай, только дополняй пустые
  и дописывай строки новой пачки)
- Журнал истории пачек: `Датасет/Разметка/<локация>/LOG.md` (создай при первом отчёте;
  журнал пополняется в хронологическом порядке и хранит справки после каждой пачки)
- Словарь: `tatar-pattern/tools/dataset/README.md`, раздел «Словарь значений»

## Старт пачки (обязательно)

2. Если новых прокси/листов ещё нет:

```bash

  --location "01.09.2026/Национальный музей РТ" --offset <N> --count 15
```

Скрипт не затирает готовые строки CSV, только дописывает кадры и новые sheet_NN.
3. Работай только по новым листам из обновлённого `sheets/index.txt`.

Если папки `Датасет/Разметка/<локация>` нет вообще (новая локация):
`python3 tatar-pattern/tools/dataset/prepare.py --location "<локация>"`

## Порядок работы (экономим токены)

1. Прочитай `annotations.csv` (новые строки + хвост прошлой пачки) и `sheets/index.txt`.
2. Контактные листы по одному. Для каждого кадра: `work` / `plate` / `reject`.
   Kind из worklist править только при явной ошибке + запись в `notes`.
   `reject` — размыто; **дубль затвора без новой информации**; не орнамент/не предмет.
   Дубль vs «очень похожая другая работа / другой разворот / деталь»: сначала сравни
   содержимое (другой текст, другая страница) и блики. Если это тот же кадр дважды —
   `kind=reject`, `usage_scope=исключить`, в notes номер оригинала.
3. Табличку открывай в полном прокси (`DSCxxxx.jpg`) — только их. Перепиши в
   `title_ru`, `title_tt`, `title_en`, `dating`, `dimensions`, `technique`, `author`,
   `description` как на табличке, ничего не сокращай и не «улучшай». Не видно — пусто.
4. Сопоставь табличку с предметами:
  - табличка обычно ПОСЛЕ кадров предмета, между ними бывают детали;
  - одна табличка → несколько предметов: номер в `plate_frames` у каждого;
  - несколько кадров одного предмета → один `artifact_code`; атрибуция у первого кадра;
  - `artifact_code` = префикс + номер первого кадра: `KS-9240`
    (Кул Шариф → KS, Национальный музей РТ → NM, Хазинэ → H,
    Старо-татарская слобода → STS, Азимовская мечеть → AM, Аль Марджани → AM2,
    Дом Муллина → DM).
  - Табличка к предмету **прошлой** пачки: допиши поля в уже существующую строку,
    не создавай новый код.
5. По изображению предмета:
  - `artifact_type` — из словаря;
  - `origin`: `татарское` — татарский предмет/орнамент (наличники, ичиги, тюбетейки,
    полотенца, шамаили, казанская кожаная мозаика, тюльпаны/пальметты);
    `общеисламское` — исламская каллиграфия/рукописи без татарской атрибуции;
    `иное` — Магриб, Осман, Индия, Судан, Андалусия, Иран/Сефевиды, Китай, Дагестан и др.;
    `неизвестно` — если не ясно;
  - `authenticity`: «реплика»/«копия»/«автор реплики»/«муляж» на табличке → `реплика`;
    современная авторская работа → `новодел`; музейный подлинник с датой → `оригинал`;
  - `usage_scope`: татарское + оригинал/новодел → `рид_и_обучение`;
    татарское с плохим кадром → `только_обучение`;
    реплика чужого автора или не татарское → `контекст`; брак → `исключить`;
  - `quality_flags`: `reflection` (блик/отражение в стекле — ставить, если пятно света
    или силуэт фотографа видны на прокси; не занижать до `ok`), `angle`, `blur`,
    `partial`, `lowlight`, `colorcast`, или `ok`;
  - `confidence` 0..1 за сопоставление табличка↔предмет и чтение текста.
    Ниже 0.7 — обязательно поясни в `notes`.
6. Пиши в `annotations.csv` (UTF-8, запятая, кавычки для запятых/переносов).
   Порядок и набор колонок не менять.
7. После каждого нового листа — короткий отчёт. В конце пачки — сводка,
   `confidence < 0.7`, дубли/исправления kind, хвост в следующую пачку.
   Обнови STATUS.md (прогресс, offset следующей пачки, открытые хвосты).
8. Запиши эту же итоговую справку отдельной датированной записью в
   `Датасет/Разметка/<локация>/LOG.md`. Если файла ещё нет — создай его.
   Журнал только дополняй: не переписывай предыдущие записи; перед добавлением
   проверь, что для этой пачки и offset запись ещё не существует. STATUS.md —
   актуальное состояние для продолжения, LOG.md — история завершённых пачек.

## Жёсткие правила

- НЕ додумывай: нет таблички — поля атрибуции пустые, `notes: "табличка не найдена"`.
- НЕ переводи и не пересказывай текст табличек — переписывай дословно.
- Если в поле уже есть значение (человек или предыдущий чат) — не трогай,
  кроме пустых полей и явной ошибки kind / найденной таблички к старому кадру.
- Каллиграфию и рукописи Корана из Кул Шарифа не относи к `татарское` без явной
  татарской атрибуции на табличке (это в основном реплики зарубежных рукописей
  Дамир-катиба).

Импорт (`import_annotations.py`) — только когда человек скажет, что локация
закончена и CSV перепроверен. Команду в конце пачки не печатай как «сделай сейчас».

1. **Что выполнено** — диапазон кадров, объём разметки, исправления `kind`, найденные таблички, восстановленные прокси или листы.

4. **Прочее важное для продолжения** — открытые хвосты, строки с `confidence < 0.7`, решения или ограничения, которые следующему чату важно учесть.

Сверяй справку с актуальными `annotations.csv` и `STATUS.md`: не теряй незакрытые вопросы, не повторяй уже решённые проблемы как текущие и не предлагай импорт до выполнения указанного выше условия.
