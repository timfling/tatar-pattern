# Инструменты разметки датасета

Два скрипта и один промпт. Цель: превратить папку RAW-файлов и музейные таблички
в заполненную таблицу предметов (`artifacts`) в базе — с минимумом ручной работы.

## Как это устроено (в двух словах)

```text
RAW (25 ГБ)  ──prepare.py──►  прокси-JPG + контактные листы + annotations.csv (заготовка)
                                        │
                                        ▼  ИИ в новом чате Cursor смотрит листы и таблички,
                                        │  дозаполняет annotations.csv
                                        ▼
annotations.csv  ──import_annotations.py──►  annotations.sql  ──make import──►  Postgres
                                        │
                                        ▼  ты проверяешь в Adminer, ставишь review_status = 'проверено'
```

Что хранится где:

```text
Датасет/
├── Исходные изображения/<дата>/<локация>/     RAW + твоя таблица .numbers (не трогаем)
├── Прокси/<дата>/<локация>/DSCxxxx.jpg        лёгкие JPG 1600px — их смотрит ИИ
│                            sheets/           контактные листы 3×3 + index.txt
└── Разметка/<дата>/<локация>/
    ├── worklist.csv       экспорт твоей таблицы из Numbers
    ├── manifest.csv       все кадры по порядку + work/plate по твоему списку
    ├── annotations.csv    ГЛАВНЫЙ ФАЙЛ: заготовка → заполняет ИИ → проверяешь ты
    └── annotations.sql    результат import_annotations.py
```

## Шаг 1. Подготовить локацию

Из папки «Разработка» в терминале:

```bash
python3 tatar-pattern/tools/dataset/prepare.py --location "01.09.2026/Кул шариф"
```

Или сразу всё (~10 минут, 587 кадров):

```bash
python3 tatar-pattern/tools/dataset/prepare.py --all
```

Скрипт ничего не устанавливает: конвертация через встроенный в macOS `sips`,
экспорт `.numbers` — через само приложение Numbers (оно откроется и закроется само).
Повторный запуск не пересоздаёт готовые прокси и **не затирает** `annotations.csv`,
если он уже есть (чтобы не потерять разметку). Если нужно пересоздать заготовку —
удали файл руками.

## Шаг 2. Разметка ИИ в новом чате

Открой новый чат в Cursor, вставь содержимое **`ПРОМПТ-для-нового-чата.md`**.
Локация и пачка (до 15 кадров) берутся из
`Датасет/Разметка/<локация>/STATUS.md` — это память между чатами.
Прокси следующей пачки: `extend_batch.py --location … --offset N --count 15`
(не затирает уже заполненный `annotations.csv`).

Импорт в базу — только после разметки всей локации и твоей перепроверки CSV.

## Шаг 3. Загрузить в базу

```bash
python3 tatar-pattern/tools/dataset/import_annotations.py "Датасет/Разметка/01.09.2026/Кул шариф/annotations.csv"
cd tatar-pattern/db
make import FILE="../../Датасет/Разметка/01.09.2026/Кул шариф/annotations.sql"
```

Скрипт проверяет значения по словарю и печатает предупреждения (например,
«табличка DSC9241 не найдена») — прочитай их перед импортом. Все строки попадают
в базу со статусом `авто`. Повторный импорт обновляет строки `авто` и **не трогает**
те, что ты уже перевёл в `проверено`.

## Шаг 4. Проверка

В Adminer (http://localhost:8080) открой таблицу `artifacts`, фильтр
`review_status = 'авто'`. Смотришь предмет → правишь при необходимости →
ставишь `проверено` (или `отклонено`). Только предметы с
`usage_scope = 'рид_и_обучение'` и `review_status = 'проверено'` пойдут в РИД.

## Словарь значений (используется и ИИ, и импортом)

| Поле | Допустимые значения |
|---|---|
| `kind` | `work` — предмет; `plate` — табличка; `reject` — брак/дубль/не орнамент |
| `artifact_type` | архитектура, плитка, витраж, текстиль, вышивка, кожа, ювелирное, керамика, резьба, рукопись, каллиграфия, шамаиль, иное |
| `origin` | татарское, общеисламское, иное, неизвестно |
| `authenticity` | оригинал, реплика, новодел, неизвестно |
| `usage_scope` | рид_и_обучение, только_обучение, контекст, исключить |
| `quality_flags` | через запятую: reflection, angle, blur, partial, lowlight, colorcast — или `ok` |
| `confidence` | число 0..1 — уверенность ИИ в разметке строки |

Правило по умолчанию для `usage_scope`:
- татарское + оригинал/новодел → `рид_и_обучение`
- татарское, но качество кадра плохое → `только_обучение` или `исключить`
- общеисламское / иное / реплика чужого автора → `контекст` (храним, никуда не включаем)
