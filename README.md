# TATAR PATTERN

Код сервиса генерации орнаментальных паттернов на основе татарских мотивов.

## Структура

- `tatar-pattern/frontend` — Next.js 16.4, React 19, TypeScript.
- `tatar-pattern/backend` — Python 3.12+, FastAPI, Pillow; API и генератор.
- `tatar-pattern/db` — PostgreSQL 16, миграции и тестовые сиды.
- `tatar-pattern/deploy` — Docker, Caddy, скрипты развёртывания и резервного копирования.
- `tatar-pattern/tools` — инструменты подготовки каталога.
- `ИИ` — код SDXL/LoRA-сервиса, обучения и подготовки GPU-среды.

Начните с [описания сайта](tatar-pattern/README.md). Контракт API:
[tatar-pattern/API-CONTRACT.md](tatar-pattern/API-CONTRACT.md).
Самостоятельное обновление репозитория: [GITHUB.md](GITHUB.md).

## Состав публикации

Репозиторий содержит исходники, тесты, технические инструкции, шаблоны настроек
и необходимые ресурсы интерфейса. Он не содержит бизнес-документы, историю чатов,
фотографии и изображения датасета, обученные модели, локальную БД, секреты,
результаты генерации, архивы релизов и зависимости.
Метаданные композиции внутри backend нужны генератору и включены в код.
Полный рабочий каталог импортируется отдельно: без него генерация требует
тестовых фикстур или возвращает `CATALOG_EMPTY`. GPU-часть требует отдельного
окружения, моделей и конфигурации; готовые веса здесь не распространяются.
